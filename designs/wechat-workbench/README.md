# 公众号工作台 UI 原型

本地视觉与交互原型，不修改 `app/` 或 `server/` 业务实现。

## 设计范围

- 一期：文章编辑、手机预览、样式切换、复制到公众号。
- 二期：爆文发现、赛道筛选、收藏、选题观察、写作简报进入编辑器。
- 首页默认进入一期排版。二期通过导航预览，不代表已上线。

视觉参考当前项目：`app/src/index.css`、`TypesetterView.tsx` 与现有绿色主操作按钮。采用系统字体、白色工作区、浅灰绿色背景、翡翠绿强调。

## 数据依据

用户提供：[次幂数据，获取10w+爆款文章](https://www.showdoc.com.cn/2265380957870963/11559060626817123)。2026-11-13 经公开页面读取。

接口：`POST /api/v2/10w/articles`。文档请求条件包括分类、最早发布时间、分页 ID；返回文章标题、账号、封面、原文链接、发布时间、阅读、互动、热度等。当前没有提供粉丝数或账号历史阅读基线，因此原型不计算“低粉”、爆发倍率或自创爆文分。

所有标题、账号、数字、选题观察与简报均为界面示例，不是接口实际返回或模型真实分析。前端筛选、排序、收藏、选题载入与复制仅用于本地演示，不发起真实模型或付费接口请求。日期按 Asia/Taipei 2026-11-13 展示。

说明：文档将 `like_num` 标为在看、`old_like_num` 标为点赞；与部分常见命名直觉不同，后续接入需以供应商确认和真实响应核对。本原型不展示含义尚未充分说明的异常值。

## 使用

打开 `prototype.html` 可切换两个页面。按“生成写作简报”查看示例，再按“带入排版”进入一期编辑器。可编辑正文、切换主题、搜索筛选和收藏。

预览图：`01-typesetter.png`、`02-discovery.png`。原型已经通过临时 HTTP 服务加载和真实浏览器检查；交付后临时服务关闭。
