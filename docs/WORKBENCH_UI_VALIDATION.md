# 一期工作台 UI 验证

日期：2026-11-13。实现依据：用户确认的 `designs/wechat-workbench/prototype.html`。

## 实际改动

- 工作台侧栏、面包屑、主操作区、独立外观工具栏与编辑预览双栏落入 React 页面。
- 默认使用手机 375px 预览，可切换至 677px；导出使用当前预览节点的实际尺寸。390px 小屏下预览框会适应可用宽度，375px 为设计目标宽度。
- 保留原有主题、版式、图片风格、云预设、风格方案、字体与组件样式，以及 AI、飞书、本地导入、X 输出、图片导出和视频入口。
- 显示真实本地草稿保存状态。品牌和同页导航使用 React Router Link，避免意外全页刷新；去登录、配置或视频前主动保存当前正文。
- 小屏提供导航菜单和可用的样式弹层。排版通知放到底部，避免遮挡顶栏操作。
- 爆文发现和我的选题仅展示二期规划。未调用次幂接口，未将示例榜单放入实际产品。

## 验证结果

- 服务器模式构建通过；OSS 模式构建通过，OSS 产物隔离在 `output/workbench-ui/oss-build`。
- 新外壳与 ToastStack 定向 ESLint 通过。未将原项目全量 ESLint 问题声明为已解决。

## 专注全屏补充验证

排版主操作区新增“专注全屏”，进入后隐藏侧栏、顶部工作台导航、标题介绍和底部规划提示，编辑与预览区域同时扩大。保留草稿状态、样式工具、AI、复制、导出和退出入口。浏览器原生全屏以整个文档为根节点，确保现有导出与 AI 弹层仍可显示；未支持或拒绝原生全屏时保留页面内专注布局。

浏览器脚本已验证原生全屏成功、按钮退出、Esc 退出、模拟原生能力不可用时的回退、正文保持不变、全屏中打开导出，以及小屏无横向溢出。图片为 `output/workbench-ui/05-focus-fullscreen.png`。新增组件定向 ESLint 通过。

## 明亮 / 暗黑皮肤补充验证

皮肤切换位于“工作台设置 → 外观皮肤”，排版主操作区不再放置切换按钮。覆盖侧栏、工作区、编辑器、工具栏、下拉菜单、风格设置与已标记的常用弹窗。选择保存在 `gzh_ui_skin`，应用启动时恢复，并可响应其他同源页面的存储变更。浏览器存储不可写时仍允许当前页面切换。全屏内保留设置图标，通过同一面板切换。

文章主题与界面皮肤分离：浏览器已核对切换前后文章预览 HTML 与背景保持一致。刷新恢复、暗黑风格弹层、专注全屏内切换及小屏切换均通过，原有复制、导入撤销、图片导出回归通过。服务器模式构建和新增皮肤服务、外壳的定向 ESLint 通过，无页面 JavaScript 错误。

实际截图：`output/workbench-ui/06-dark-skin.png`、`07-dark-focus.png`、`08-dark-mobile.png`。本次未将登录、视频对比与独立控制台整体重新设计为暗黑页面；皮肤主要覆盖文章工作台与其常用弹窗。
