# 排版工作台个人API

更新：2026-11-15。

生产环境和本地环境均允许游客、普通用户、VIP设置个人API。工作台设置展示API Key、Base URL和模型，保存在当前浏览器的原有openai_api_key、openai_api_base、openai_model键中；不上传到账号数据库，不随登录或退出自动切换。共用设备请自行清空配置。

AI排版、封面方案及小红书图文生成直接请求用户填写的OpenAI兼容服务商。配图规划与渲染使用浏览器实现，结构化内容可调用个人API；当前场景图回退为信息图。个人密钥缺失或请求失败时，不自动使用平台密钥或额度。文章保存、服务器图片上传等仍保留真实登录要求。

生产浏览器直连需要服务商支持CORS；HTTPS网站使用HTTPS接口。开发环境沿用已有同源开发代理。这里没有添加公网匿名转发任意URL的代理。

会员平台API列入[待办](TODO.md)，以后需增加用户主动选择、后端会员校验、额度和使用记录。本轮不提供会员平台来源切换。原有后端模型路由和爆文库AI简报沿用既有实现，尚未统一到未来会员方案，不能把个人API的前端放行规则用于后端权益判断。

验证包括：

- 生产模式打包的服务模块测试个人请求地址、模型和Authorization，站点登录令牌不作为模型密钥；缺少密钥和服务商拒绝时不回退平台。
- 真实Chrome加载自托管生产构建，游客、free和vip均可设置、保存刷新并完成模拟AI排版，游客不跳登录。
- 检查设置弹窗桌面明亮、手机暗黑实际截图；测试只用临时数据库和模拟模型响应。

测试入口：server/test/personal-ai.test.mjs、server/test/personal-ai-browser.mjs。报告与截图在output/personal-ai。未验证真实模型质量和所有供应商CORS，真实付费请求为0；本地验证不代表公网服务器已部署。
