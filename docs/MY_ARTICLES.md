# 我的文章

当前生产入口标注“后续实现”，仅展示规划说明；云端文章管理等待账号功能完善后开放。下面记录已保留的开发模式实现，生产不展示保存入口且/api/articles返回404，既有数据保留。

## 使用

1. 真实登录后，在排版页点击“保存文章”，填写标题并保存到服务器。
2. 从侧栏或手机导航进入“我的文章”，可按标题搜索、继续加载、重命名和删除。
3. 点击“继续排版”后确认载入。当前编辑正文先保留为撤销快照，可从“AI工具 → 撤销：载入已保存的文章”恢复。本机存储失败时不载入。
4. 打开或保存文章后，本机记住当前文章的标题、ID与版本号。刷新或重新进入编辑器时恢复关联，保留本机未保存的修改，不自动从服务器覆盖正文；重新保存默认更新该文章，仍校验版本冲突。
5. 保存对话框可勾选“另存为新文章”；也可选择“保留当前正文，作为新稿继续编辑”，确认后脱离原文章，原服务器记录保持不变。载入另一篇文章后撤销，会一并恢复原正文与原文章关联。

本机草稿仍在停止输入800毫秒后自动保存。服务器文章需要手动点击保存，不进行自动同步。保存请求提交后的继续编辑只留在本机，需再次保存才能更新服务器。

文章关联按账号保存在当前浏览器，清理站点数据后需从文章库重新打开。服务器已保存但本机关联保存失败时会明确提示；如果其他页面更新或删除原文章，保存会报错，可保留当前正文另存或重新载入。暂不提供同账号多标签页协同编辑。

## 数据边界

- 自有Node服务器及本地Vite调测均使用 `server/data/gzh.sqlite` 的 `saved_articles` 表。表在启动时兼容创建，不迁移或覆盖现有草稿。
- 每篇只保存标题和Markdown正文；文章排版组合沿用已有预设功能，不随正文存储。图片保存原地址，不自动上传、修复失效链接或跨平台转存。
- 真实会话决定归属，调试身份不能访问真实用户文章。列表、详情、修改及删除均校验所有者。
- 更新和删除携带版本号。其他页面已更新时返回409，保留当前编辑内容，可另存为新文章或重新载入新版。
- 删除需二次确认，永久删除服务器记录，本机编辑草稿不变。暂不提供回收站或历史版本库。
- 标题1至200字符，正文最多100万字符。列表每页30篇，搜索标题，按更新时间和ID稳定排序，使用绑定搜索条件的游标继续加载。
