# 文章库日常使用增强

范围：沿用现有去重及手动采集，增加日期查询记录和跳过已成功当日查询的补采。不开启定时器或真实付费调用，不扩展低粉判断。

1. 从全部任务步骤及兼容旧任务读取指定赛道、榜单、最多60天的日期记录，区分当日成功、区间涉及、尚无成功记录，并显示最近尝试结果。
2. 逐日补采可跳过成功的当日查询，区间查询不作为逐日完成依据。前端显示预算预估，后端在提交时重新计算，跳过日期记入任务参数；全部已查时不创建任务、不计预算。
3. 文章库增加可展开的日期记录；采集记录显示跳过日期和成功数量。调测身份可看日期记录，付费入口权限保持原样。
4. 验证旧历史不受最近20条限制、不同榜单隔离、失败重试候选及已查跳过，运行现有去重和权限测试，并检查桌面、手机真实渲染。
