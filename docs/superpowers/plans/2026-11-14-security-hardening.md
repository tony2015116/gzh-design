# 基础排版上线前安全加固

按用户授权实施，范围为导入内容HTML过滤、Node账号接口防滥用、飞书授权及凭证存储。保留现有Markdown和排版组件，不改写用户原稿，不接验证码供应商，不部署、不调用真实外部业务接口。

1. 使用维护中的HTML过滤库，集中处理Markdown渲染输出，允许常用排版标签和受限样式，移除事件属性、脚本、危险协议、嵌入及覆盖界面的CSS。以恶意HTML、代码示例和原有排版回归验证。
2. Node账号接口以持久化原子计数限制注册、登录与改密；IP只来自连接或显式信任的本机反向代理。登录失败计数绑定邮箱与可信客户端地址，校验邮箱及输入长度，不输出数据库错误详情。
3. 飞书state使用随机值，服务端哈希存储，绑定用户、会话、回调地址、应用和有效期，原子消费并拒绝重放。凭证使用AES-GCM与按用户/字段绑定的附加数据；Node密钥用环境变量或权限受限的独立文件持久化。启动时校验密文，事务迁移现有记录，密钥缺失或错误时停止，禁止静默生成替代密钥。
4. 临时库及模拟上游验证授权全流程、重放、跨会话、过期、密文和重启，浏览器验证恶意导入不执行及正常排版不回归。明确区别本地验证与真实飞书、Linux部署验收。
