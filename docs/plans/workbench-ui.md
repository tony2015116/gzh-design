依据：用户确认的 `designs/wechat-workbench/prototype.html`。先上线一期排版，二期爆文功能仅预留规划提示。

## 范围与决策

- 在当前工作区实施，保留此前自托管改造和用户已有改动，不提交或发布。
- 提取工作台外壳组件及专用样式，沿用现有编辑器、预览、主题、云预设、AI、导入与导出逻辑。
- 新增侧栏、面包屑、排版标题区与样式工具栏。常用复制和图片导出保持直达，视频对比放入侧栏。
- 默认手机宽度 375px，可切换 677px；复制与导出继续使用原预览节点。
- 草稿状态真实反映本地写入结果。二期页面不放模拟排行榜，不请求次幂接口。
- 小屏使用可滚动的上下编辑/预览结构，菜单与导出弹窗保持可用。
